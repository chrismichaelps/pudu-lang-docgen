# pudu-lang-docgen

Documentation publishing for Pudu. The planned package converts articles and public declarations
into a searchable static website with accessible navigation and cross-references.

Development is in progress. No version is released until the [capability ledger](wiki/architecture/CAPABILITIES.md)
and release gates are verified. The repository follows the layout of pudu-lang-log.

# Vocabulary

- **Document**: source path and UTF-8 text, interpreted as article, metadata, or navigation.
- **Page**: safe output path, title, UID, rendered body, headings, and extracted destinations.
- **Reference**: globally unique UID, display name, and checked destination.
- **Artifact**: relative output path and fully rendered text. A plan contains no effects.
- **Diagnostic**: stable code, source path, one-based line, and actionable message.
- **Module**: a named contract hiding one cohesive responsibility.
- **Seam**: an explicit boundary to files, tools, or another source format.
- **Depth**: useful behavior hidden behind a small contract, evaluated by the deletion test.
